# tetsuo-ai/homebrew-agenc

Homebrew tap for the [AgenC CLI](https://github.com/tetsuo-ai/agenc-core).

## Install

```bash
brew install tetsuo-ai/agenc/agenc
```

## Upgrade

```bash
brew upgrade agenc
```

The formula installs the immutable architecture-specific AgenC runtime together
with its reviewed private Node.js 26.5.0 executable. A host Node installation is
not required.

Homebrew upgrades AgenC and its private Node runtime together. Use
`brew upgrade agenc`, not `agenc update`, for this installation.
